2. Why is strict type enforcement preferred in system-level software but not in scripting
languages?
System-Level Software (C,C++,Rust): Strict Typing:
- Performance: No runtime type checking = faster execution, compiler optimizes ahead of time
- Safety: Type errors caught before running → prevents system crashes, security holes, memory corruption
- Predictability: Exact memory usage known beforehand, critical for embedded systems/OS

Scripting Languages (Python, JavaScript, Ruby) : Dynamic Typing:

Fast development: Don't declare types, write code quickly.
Flexibility: Same code handles different types, processes varied inputs
Lower risk: Script crashes don't bring down systems, easy to fix .
Priority: Speed of writing code > speed of running code
